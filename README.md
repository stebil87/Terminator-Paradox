# Terminator-Paradox
# Code Release — The Terminator Paradox

This repository accompanies the paper *The Terminator Paradox: When Optimal Strategies Destroy Their Own Foundations*. It contains a FAIR, fully generic implementation of backward induction for finite extensive-form games, used to validate:

- subgame-perfect equilibrium computation,
- the centipede-game backward-induction paradox,
- the endogenous-game-tree construction,
- the self-invalidating equilibrium phenomenon.
